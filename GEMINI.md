# ForgeBee — Gemini Context Pointer

For ForgeBee's full instructions, conventions, and agent/skill catalog, see [CLAUDE.md](./CLAUDE.md).

ForgeBee is harness-agnostic where possible — the same skills, agents, and commands work across Claude Code, Cursor, Codex, and Gemini.

Key entry points:
- `/workflow` — full-pipeline orchestrator (planning → execution → delivery)
- `/team` — ad-hoc multi-agent coordination
- `/review-all` — pre-push quality gate
- `/plan` — phased BMAD-style planning
- `/growth` — Growth OS marketing pipeline
